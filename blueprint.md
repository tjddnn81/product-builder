
# Blueprint: Lotto Number Generator

## Overview

This document outlines the design and development of a simple, user-friendly Lotto Number Generator web application. The application will generate a random set of 6 unique lottery numbers between 1 and 45, styled in a visually appealing and modern way.

## Design and Features

### Version 1.0 (Initial Release)

*   **UI/UX:**
    *   **Layout:** A centered, clean interface for easy interaction.
    *   **Typography:** Clear, legible fonts to display the title and generated numbers.
    *   **Color Scheme:** A modern and vibrant color palette.
    *   **Visuals:** Each number will be displayed in a colored circle for better visual separation.
    *   **Interactivity:** A button to initiate the number generation with a subtle hover effect.
*   **Functionality:**
    *   **Number Generation:** On button click, generate 6 unique random numbers from 1 to 45.
    *   **Display:** The generated numbers will be displayed in a row.

## Current Plan

*   **Step 1: HTML Structure (`index.html`)**
    *   Set up the basic HTML structure with a title, a container for the numbers, and a "Generate" button.
*   **Step 2: Styling (`style.css`)**
    *   Apply styles to the body, container, number circles, and the button to create a polished look.
*   **Step 3: JavaScript Logic (`main.js`)**
    *   Implement the logic to generate and display the unique random numbers when the button is clicked.
